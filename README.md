# Amazon Environmental Crimes Observatory

**Observatorio de Crimes Ambientais na Amazonia | WCS Brasil**

Independent GitHub repository for the Amazon Environmental Crimes Observatory. Original code: [acarvalho-wcs/WCS](https://github.com/acarvalho-wcs/WCS), branch `amazon-crimes-pages`.

The production application is in `amazon-crimes/public/`, with canonical records in `amazon-crimes/data/events.json` and GitHub Pages publication through GitHub Actions.

Target public website: https://wcsbrintel.github.io/crimesamazonicos/

The original repository and its website remain independent and unchanged.
